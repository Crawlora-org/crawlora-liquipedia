# Liquipedia API endpoint reference and client usage

This reference lists all 12 public Liquipedia API endpoints exposed by the JavaScript/TypeScript, Python, Go, Ruby, Java, PHP, and Rust clients, including the `@crawlora-org/liquipedia`, `crawlora-liquipedia`, and `crawlora-liquipedia` packages. The clients call Crawlora's hosted API. Set `CRAWLORA_API_KEY` to a key for your Crawlora account before making requests. Service usage is billed under that account. These clients do not run a browser or scrape Liquipedia locally; Crawlora is independent from and not endorsed by Liquipedia or its owners.

The package tracks the public API contract revision `sha256:158c4854176f104cc7b6851de936ca85b4f0ff757b4bcd2ca75ea6cd4fef0918` bundled with release `0.1.0`. Maintainers can preview daily contract updates with the repository's `Sync live API contract` workflow; unchanged contracts do not produce package releases.

All language packages expose the selected public API operations in the bundled contract. JavaScript uses camelCase methods, Python and Rust use snake_case methods. JavaScript, Python, and Rust methods are grouped under `liquipedia`; Rust uses typed parameter structs and returns the complete HTTP response.

## Client forms

- JavaScript: import `LiquipediaClient` (also exported as `Client`) from `@crawlora-org/liquipedia`; use `new LiquipediaClient({ apiKey })` and `await client.method({ ... })`.
- Python: import `LiquipediaClient` (also exported as `Client`) from `crawlora_liquipedia`; use `with LiquipediaClient(api_key=...) as client` and `client.method(...)`.
- Python async class: `AsyncLiquipediaClient`, used with `async with` and `await`.
- Rust: add `crawlora-liquipedia` with Cargo; import `Client` and the generated operation parameter struct, then call `client.liquipedia.<snake_case_method>(params).await`. See the [Rust example](https://github.com/Crawlora-org/crawlora-liquipedia/blob/main/rust/examples/quick_start.rs).

See the package READMEs for installation details. Keep API keys in environment variables or a secret store; do not commit them.
